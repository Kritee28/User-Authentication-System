# User Authentication System

A full-stack user authentication application built using React.js, Node.js, Express.js, and MySQL. The project provides a foundation for user registration, login, authentication, and session management.

## Tech Stack

**Frontend**
- React.js
- JavaScript
- HTML
- CSS

**Backend**
- Node.js
- Express.js

**Database**
- MySQL

## Features

- User Registration
- User Login
- Authentication
- Session Management
- Frontend and Backend Integration
- MySQL Database Connectivity

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Kritee28/User-Authentication-System.git
cd User-Authentication-System
```

### 2. Install Dependencies

Install the frontend and backend dependencies using the respective package.json files.

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in the backend directory and configure your database credentials and application secrets.

Never commit your `.env` file to GitHub.

### 4. Run the Application

Start the backend server and frontend development server using their respective start scripts.
